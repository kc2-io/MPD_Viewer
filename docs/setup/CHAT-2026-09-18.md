## Behavior

Each viewer shows official chat for its assigned channel by default. Hide/show retains the video, chat iframe, playback state and session. Wide windows show chat beside video; narrow windows stack it underneath and permit scrolling, preserving at least 400×300 video geometry. New viewer windows start at 1180×720.

The native app injects the shared chat helper into its configured hosted document. The bundled wrapper serves the same helper/CSS and shows a clearly simulated transcript in Demo, without Twitch requests. The hosted source snapshot and deployed website were not changed.

## Limits and security

The narrow navigation addition permits only HTTPS `www.twitch.tv/embed/{assigned-channel}/chat` with exactly the actual parent hostname. It adds no chat IPC capability, management command, OAuth scope, credential access or automated messages.

The previous native audio issue remains: actual Twitch SDK volume reported 0.5 despite requested 0.25. This change does not claim to fix audio or verify viewer-session sharing, Turbo, or native grid functionality.

No website deployment, release tag, published release, signing enablement or credential change is part of this implementation. Diagnostic builds remain unsigned. Merge only after the five protected CI checks pass; native Windows/macOS/Linux compilation is separate from actual chat runtime acceptance.
