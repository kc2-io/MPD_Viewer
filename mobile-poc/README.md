# MPD Viewer mobile POC

This is an emulator-oriented interaction POC for Android and iOS. It reuses
`mpd-core` so priority and capacity selection remain in Rust. The media surfaces
and chat transcript are deliberately simulated: this POC does not contact
Twitch, claim playback, or bypass Twitch's embed rules.

## Fast browser preview

From the repository root:

```sh
python3 -m http.server 4173 --directory mobile-poc/ui
```

Open `http://127.0.0.1:4173/?preview=1` and use responsive/device emulation. The
`preview=1` bridge is a browser fixture only; native builds call the Rust
controller.

## Desktop smoke run

Install the Tauri system prerequisites, then run:

```sh
cargo run --locked -p mpd-viewer-mobile-poc --features custom-protocol
```

## Android emulator

The Android Studio project is already generated in `src-tauri/gen/android`.
Install Android Studio, its SDK Platform, Platform-Tools, NDK, Build-Tools and
Command-line Tools; set `JAVA_HOME`, `ANDROID_HOME`, and `NDK_HOME`; then install
the Tauri CLI and the emulator Rust target:

```sh
cargo install tauri-cli --version '^2.0.0' --locked
rustup target add x86_64-linux-android
cd mobile-poc
cargo tauri android dev --open
```

To build an installable emulator APK without launching Android Studio:

```sh
cd mobile-poc
cargo tauri android build --debug --target x86_64 --apk --ci
adb install -r src-tauri/gen/android/app/build/outputs/apk/universal/debug/app-universal-debug.apk
```

## iOS simulator

iOS builds require macOS with full Xcode and CocoaPods. On that host:

```sh
rustup target add aarch64-apple-ios x86_64-apple-ios aarch64-apple-ios-sim
cd mobile-poc
cargo tauri ios init --ci --skip-targets-install
cargo tauri ios dev --open
```

The Apple project is generated by the installed CLI on macOS. Keep the
checked-in Rust/UI source authoritative and review generated platform changes
before committing them.

## What to evaluate

- 2×2 overview at phone and tablet sizes without horizontal overflow.
- Start, pause/resume, stop, limit, volume and mute interactions.
- Rust-owned top-priority selection and retained session IDs after reorder.
- Audio + chat navigation as a product concept.
- Accessibility focus, safe-area insets, rotation, lifecycle and memory pressure.

Real Twitch acceptance is a later, separate experiment. Use a tablet landscape
viewport of at least 800×600 CSS pixels for four 400×300 video embeds. A phone
may show four assignments, but cannot show four Twitch-compliant videos at once.
